# Portfolio Website

Ez egy saját készítésű portfólió oldal, ahol bemutatom a munkáimat, a skilleimet és a fejlődésemet frontend és backend területen.

## Tech Stack

- React
- Vite

## Funkciók

- Animációk (Framer Motion)
- Modern UI / glassmorphism elemek
- Saját projektek bemutatása

## Tanultak a projekt során

- Komponens alapú felépítés React-ben
- Animációk kezelése

## Telepítés

```bash
npm install
npm run dev
